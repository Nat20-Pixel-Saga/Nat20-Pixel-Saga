# YouTube Shorts, Campaign 1 (Episodes 1-10)

One Short per episode, cut from its highlight. Each goes public the day after its episode at 13:00 Paris time and points back to the full episode.

**For each Short:** upload the MP4 from the episode's GitHub release (`C01-E00N-short.mp4`), paste the title and description, schedule it, and set **Related video** to the full episode. Cover: if YouTube lets you upload one, use `C01-E00N-short-cover.png`; otherwise pick the frame at 0:01 (it shows the hook). Then register it: Actions -> youtube -> Run workflow -> record, episode `Ns` (e.g. `1s`), its link and time.
