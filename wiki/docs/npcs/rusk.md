# Rusk

The small goblin taken alive in the raid on Brindle Cross. Spent the night tied to the Crooked Kettle's rain barrel, then talked after Oriel fed him. Speaks in short, broken sentences and calls himself by name. Now kept in the Kettle's cellar with a blanket, asleep on Maddy's onions.

| | |
| --- | --- |
| **Status** | captive |
| **Attitude** | indifferent |
| **Want** | Food, and not to be sent back to his boss. |
| **Voice** | Clipped and plain: 'Rusk not asks. Asking gets you hit.' |
